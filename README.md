# Rozetka Clone — Backend

Бекенд-частина навчального pet-проєкту — REST API для клону інтернет-магазину Rozetka.

Реалізує реєстрацію/авторизацію (JWT), список бажань та кошик, з реальною базою даних PostgreSQL.
